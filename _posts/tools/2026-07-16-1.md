## 탐색기에서 파일/폴더 숨기기

1. 프로젝트 최상단(루트)에 `.vscode` 폴더를 만들고, 그 안에 `settings.json` 파일을 생성
``` plaintext
blog/
├── .vscode/
│   └── settings.json
```

2. `settings.json`에 숨김 규칙 추가
``` json
{
  "files.exclude": {
    "**/_site": true,
    "**/.jekyll-cache": true
  }
}
```
