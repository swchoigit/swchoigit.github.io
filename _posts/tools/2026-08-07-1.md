## Extensions
* **Prettier - Code formatter** (by Prettier): 코드 정렬
* **Shopify Liquid** (by Shopify): HTML 파일 내 Liquid 문법 강조 및 코드 정렬
* **Python** (by Microsoft): Python 개발 환경
* **autopep8** (by Microsoft): `.py` 확장자 파일 코드 정렬

## 코드 정렬
`Command + Shift + P` > `Prefrences: Open User Settings (JSON)`

``` json
"[html]": {
  "editor.defaultFormatter": "vscode.html-language-features",
},
"files.associations": {
  "*.html": "liquid",
},
"[liquid]": {
  "editor.defaultFormatter": "Shopify.theme-check-vscode",
},
"[javascript]": {
  "editor.defaultFormatter": "esbenp.prettier-vscode",
},
"[css]": {
  "editor.defaultFormatter": "esbenp.prettier-vscode",
},
"[python]": {
  "editor.defaultFormatter": "ms-python.autopep8",
  "editor.formatOnSave": true,
},
```

## 탐색기에서 파일/폴더 숨기기

1. 프로젝트 최상단에 `.vscode` 폴더를 만들고, 그 안에 `settings.json` 파일을 생성
``` plaintext
blog/
├── .vscode/
│   └── settings.json
```

2. `settings.json`에 숨김 규칙 추가
``` json
{
  "files.exclude": {
    "**/_site": true,
    "**/.jekyll-cache": true
  }
}
```
