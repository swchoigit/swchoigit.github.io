## Q. 딥러닝과 머신러닝 간의 포함관계에 대해 설명해 주세요.

딥러닝과 머신러닝은 인공지능(AI) > 머신러닝(ML) > 딥러닝(DL)의 계층적 포함관계를 가진다.

### 인공지능 (AI)
인간의 지능을 모방하는 가장 넓은 개념의 컴퓨터 시스템 기술

### 머신러닝 (ML)
규칙을 직접 코딩하지 않고 데이터로부터 패턴을 학습해 예측하는 기술

### 딥러닝 (DL)
인간의 뇌 신경망을 모방한 인공신경망(ANN)을 기반으로 데이터에서 특징을 스스로 추출하고 학습하는 기술

## Q. 딥러닝의 성능 향상을 위해 고려하는 하이퍼 파라미터의 종류에는 어떤 것들이 있는지 설명해 주세요.
### 하이퍼파라미터(Hyperparameter)
학습 과정에서 모델이 가중치(𝑾)처럼 스스로 최적화하는 일반 파라미터와 달리, 모델의 학습 효율과 성능을 극대화하기 위해 사용자가 학습 시작 전에 직접 설정해야 하는 제어 변수

### 1. 학습 프로세스 제어 (Learning Process)
* **학습률 (Learning Rate):** 가중치를 업데이트할 때 이동할 단계의 크기. 너무 크면 최적점에 수렴하지 못하고 발산할 수 있으며, 반대로 너무 작으면 학습 속도가 지나치게 느려지거나 Local Minima(국소 최솟값)에 갇힐 수 있음.
* **배치 크기 (Batch Size):** 가중치를 한 번 업데이트할 때 사용하는 데이터 샘플의 개수. 크기가 크면 학습이 안정적이고 GPU 병렬 처리에 유리하지만 메모리 소모가 크고 Local Minima에 빠지기 쉽우며, 반대로 크기가 작으면 노이즈 덕분에 Local Minima를 탈출하는 데 유용할 수 있으나, 학습 불안정성이 증가함.
* **에포크 (Epochs):** 전체 데이터를 학습에 반복하여 사용하는 횟수로, 수치가 너무 적으면 과소적합(Underfitting)이 발생하고 너무 많으면 과적합(Overfitting)이 발생함.
* **옵티마이저 (Optimizer):** 손실 함수(Loss Function)를 최소화하기 위해 가중치를 어떻게 업데이트할지 결정하는 알고리즘 (예: Adam, RMSprop, SGD 등)

### 2. 신경망 구조 (Network Architecture)
* **은닉층 수 (Hidden Layers) & 뉴런 수 (Units per Layer):** 모델의 용량과 표현력을 결정하며, 신경망이 깊고 넓어질수록 복잡한 패턴을 잘 학습하지만, 과적합 위험과 계산 비용이 증가함.
* **활성화 함수 (Activation Function):** 입력값에 비선형성(Non-linearity)을 부여하여 복잡한 데이터 구조를 학습할 수 있게 만든다 (예: ReLU, Sigmoid, GELU 등).

### 3. 과적합 방지 및 규제 (Regularization)
* **드롭아웃 비율 (Dropout Rate):** 학습 중 임의로 특정 비율의 뉴런을 비활성화하여 특정 뉴런에 대한 의존도를 낮추고 제너럴한 학습을 유도
* **가중치 감쇠 (Weight Decay / L1, L2 Regularization):** 가중치의 크기가 너무 커지지 않도록 손실 함수에 페널티 항을 추가하여 모델의 복잡도를 제한
