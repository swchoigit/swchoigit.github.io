## `git commit`

### `--amend`
새로운 commit을 추가하지 않고, 방금 올린 최근 commit에 수정사항을 덮어씌우고 싶을 때

``` bash
git commit --amend --no-edit
```

## `git push`

### `--force`
원격 저장소(Remote) 강제 반영

``` bash
git push --force
```

## `git reset`

### `--soft`
작업했던 코드를 그대로 유지한 채 원하는 commit으로 돌아가고 싶을 때

``` bash
git reset --soft [Commit ID]
```

### `HEAD~1`
가장 최근 commit 취소

``` bash
git reset --soft HEAD~1
```
