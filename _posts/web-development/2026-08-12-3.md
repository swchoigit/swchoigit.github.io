## 문제 1

``` html
<button class="site-search" onclick="ninja.open()"></button>
```

돋보기 버튼을 눌렀을 때 검색 라이브러리가 실행되도록 하고 싶었다. 그런데 화면이 완전히 로딩되고 나서 라이브러리가 초기화되기 전에 버튼을 누르면 다음과 같은 에러가 발생했다.

``` text
ReferenceError: Can't find variable: ninja
```

HTML 인라인 속성 대신 스크립트 내에서 이벤트 리스너를 직접 등록하는 방식으로 변경하여 해결했다.

``` html
<button class="site-search"></button>

<script>
    document.querySelector('.site-search').addEventListener('click', (e) => {
        ninja.open();
    });
</script>
```

## 문제 2

``` html
<script>
    const response = await fetch('{{ "/search.json" | relative_url }}');
    const posts = await response.json();
</script>
```

검색어에 따라 글 목록을 불러오기 위해 API를 연결했는데, 일반 스크립트의 최상위에서는 `await`를 직접 사용할 수 없어 에러가 발생했다. 이를 해결하기 위해 `async` 익명 함수를 `DOMContentLoaded` 이벤트 핸들러로 전달했다.

``` html
<script>
document.addEventListener('DOMContentLoaded', async (event) => {
    const response = await fetch('{{ "/search.json" | relative_url }}');
    const posts = await response.json();
});
</script>
```

추가로 조사해 보니, `<script>` 태그에 `type="module"` 속성을 추가하면 같은 결과가 나온다고 한다. `DOMContentLoaded` 방식과의 차이점은 `DOMContentLoaded`는 이벤트 콜백 내에서 필요한 처리를 진행하며, 필요시 선언한 변수를 전역 스코프에 바인딩할 수 있고, 모듈 스크립트는 `defer` 속성처럼 DOM 파싱이 완료된 후 실행되며, 독자적인 모듈 스코프를 가져 내부 변수가 전역 스코프를 오염시키지 않는다.

``` html
<script type="module">
    const response = await fetch('{{ "/search.json" | relative_url }}');
    const posts = await response.json();
</script>
```
