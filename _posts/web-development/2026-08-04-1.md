## Reset

```css
* {
  margin: 0;
  padding: 0;
}

*,
*::before,
*::after {
  box-sizing: border-box;
}

a {
  color: inherit;
  text-decoration: none;
}

button {
  background: none;
  border: none;
  cursor: pointer;
}

table {
  border-collapse: collapse;
}
```

## Layout
### Grid

```scss
.grid__wrapper {
    display: grid;
    gap: 1.5rem;
    grid-template-columns: repeat(4, 1fr);

    @media (max-width: 1024px) {
      grid-template-columns: repeat(3, 1fr);
    }
    @media (max-width: 768px) {
      grid-template-columns: repeat(2, 1fr);
    }
    @media (max-width: 480px) {
      grid-template-columns: repeat(1, 1fr);
    }

    .grid__item {
      width: 100%;
    }
}
```

```css

  width: 100%;
  height: 52px;
  border-bottom: 1px solid #b6bfb8;

  .site-wrapper {
    height: 100%;
    display: flex;
    justify-content: space-between;
    align-items: center;

    .site-logo {
      white-space: nowrap;
      flex-shrink: 0;
    }
  }

  .site-menu {
    list-style: none;
    display: flex;
    align-items: center;
    gap: 1em;

    li {
      white-space: nowrap;
    }

      font-size: 14px;
    }

    @media (max-width: 833px) {
      display: none;
    }
  }

  .site-actions {
    display: flex;
    align-items: center;

      padding: 0 calc(8px / 1);
    }

    }
  }

    width: 20px;
    height: 52px;
  }
}

```
