```python
def compare_numbers(num1, num2):
    if num1 != num2:
        if num1 > num2:
            return f"{num1}, {num2}"
        else:
            return f"{num2}, {num1}"
    else:
        return f"{num1}"
```

> [!tip]
> 파이썬 내장 함수인 `max()`와 `min()`을 사용하면 코드 분기를 훨씬 단순화할 수 있다.

```python
def compare_numbers(num1, num2):
    if num1 == num2:
        return f"{num1}"
    
    return f"{max(num1, num2), min(num1, num2)}"
```
