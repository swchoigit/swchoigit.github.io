## 1차 시도:

```python
def compress_string(s):
	repeat = 0

	for i in range(0, len(s)):
		if s[i] == s[i+1]:
			repeat += 1

	return f"{s[i]}{repeat}"

compress_string("aaabbaaa")
```

> [!warning]
> * `return`문의 위치
> * `IndexError`
> * `repeat`의 초깃값
> * `else` 문의 부재

## 2차 시도

```python
def compress_string(s):
	repeat = 1

	for i in range(0, len(s)):
		if s[i] == s[i+1]:
			repeat += 1
		else:
			result += f"{s[i]}{repeat}"
			repeat = 1

		return result

compress_string("aaabbaaa")
```

> [!warning]
> `IndexError`

## 최종 코드

```python
def compress_string(s):
	repeat = 1

	for i in range(0, len(s)-1):
		if s[i] == s[i+1]:
			repeat += 1
		else:
			result += f"{s[i]}{repeat}"
			repeat = 1
			
	result += f"{s[-1]}{repeat}"
	
	return result

compress_string("aaabbaaa")
```
