## 1차 시도

```python
def add_numbers():
	num1 = int(input("첫 번째 숫자를 입력하세요: "))
	num2 = int(input("두 번째 숫자를 입력하세요: "))
  
	if (type(num1) is not int or type(num2) is not int):
		return "올바른 숫자를 입력하세요."
	
	return num1 + num2
```

> [!warning]
> `input()`의 결과는 항상 문자열이다.

## 2차 시도

```python
def add_numbers():
	num1 = input("첫 번째 숫자를 입력하세요: ")
	num2 = input("두 번째 숫자를 입력하세요: ")
  
	if (not num1.isdecimal() or not num2.isdecimal()):
		return "올바른 숫자를 입력하세요."
	
	return int(num1) + int(num2)
```

> [!warning]
> * 입력값이 정수가 아닌 경우 에러가 발생할 수 있다.
> * 잘못된 값을 입력한 경우 프로그램을 종료하는 것이 아니라 재입력을 받아야 한다.

## 최종 코드

```python
def add_numbers():
    while True:
        num1 = input("첫 번째 숫자를 입력하세요: ")
        num2 = input("두 번째 숫자를 입력하세요: ")

        if (num1.isdecimal() and num2.isdecimal()):
            return int(num1) + int(num2)

        print("올바른 숫자를 입력하세요.")
```
