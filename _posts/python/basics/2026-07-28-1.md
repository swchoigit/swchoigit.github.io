## 파일 입력
```python
output = "output"

with open('output.txt', 'w', encoding='utf-8') as f:
    f.write(output)
```

## 파일 출력

### Before

```python
import csv

def read_file(filename):
    f = open(filename, 'r')
    lines = f.readlines()
    f.close()

    result = []

    lines.pop(0)

    for l in lines:
        l = l.strip()
        result.append(l.split(","))

    return result
```

## 코드 리뷰

### 1. `with` 구문 사용

``` python
# Before
f = open(...)
f.close()

# After
with open(...)
```

* `f.close()`를 명시적으로 호출하지 않거나 중도 에러 발생 시, `f.write()`의 인자가 디스크에 완전히 기록되지 않을 수 있다.
* `with` 구문을 사용하면 블록을 벗어날 때 자동으로 파일이 닫히므로 안전하다.

### 2. `lines.pop(0)`

``` python
# 방법 1: 슬라이싱
f.readlines()[1:]

# 방법 2: 이터레이터 활용 (권장)
next(f)
```

* `pop(0)`은 첫 요소를 뺀 뒤 뒤쪽의 모든 데이터를 앞으로 당기는 대이동 연산이 발생하여 비효율적이다.
* `next(f)`는 메모리에 파일 전체를 올리지 않고 한 줄만 건너뛰는 이터레이터 방식으로 대용량 파일 처리 시 성능이 극대화된다.

### 3. 명시적 인코딩 설정
한글 깨짐 에러 방지를 위해 인코딩을 명시해 주는 것이 좋다.

``` python
# Before
open(filename, 'r')

# After
open(filename, 'r', encoding='utf-8')
```

### After

```python
def read_file(filename):
    with open(filename, 'r', encoding='utf-8') as f:
        next(f)
        return [line.strip().split(",") for line in f]
```
