## 1번 시도

```python
def countdown_timer():
    seconds = int(input("타이머를 시작할 시간(초)을 입력하세요: "))

    print("타이머 시작!")

    if (seconds > 0):
        for i in range(seconds, 1, -1):
            print(i)
            print(1)

    print("타이머 종료!")
```

> [!warning]
> * `range`의 끝 값은 포함되지 않는다.
> * 카운트다운 숫자가 하나 출력될 때마다 숫자 1이 계속 같이 출력된다.

## 2번 시도

```python
def countdown_timer():
    while True:
        seconds = input("타이머를 시작할 시간(초)을 입력하세요: ")

        if (seconds.isdecimal()):
            seconds = int(seconds)

            if (seconds > 0):
                print("타이머 시작!")

                for i in range(seconds, 0, -1):
                    print(i)

                print("타이머 종료!")
                break
            else:
                print("올바른 값을 입력해 주세요.")
        else:
            print("올바른 값을 입력해 주세요.")
```

> [!tip]
> * 중복된 `else` 블록 합치기
> * 실제 타이머 효과 주기 (`time.sleep`)

## 최종 코드

```python
import time


def countdown_timer():
    while True:
        seconds = input("타이머를 시작할 시간(초)을 입력하세요: ")

        if (seconds.isdecimal() and int(seconds) > 0):
            seconds = int(seconds)

            print("타이머 시작!")

            for i in range(seconds, 0, -1):
                print(i)
                time.sleep(1)

            print("타이머 종료!")
            break
        else:
            print("올바른 값을 입력해 주세요.")
```
