## 1차 시도: 실패

```python
vowels = ["a", "e", "i", "o", "u"]

def remove_vowels(s):
    i = 0
    s_list = list(s)

    for i in range(i, len(s_list)):
        if s_list[i] in vowels:
            del s_list[i]

    return s_list
```
> [!warning]
> * 비교하려는 문자열의 길이가 맞지 않을 수도 있다.
> * 불필요한 `i` 선언


## 2차 시도: 실패

```python
vowels = ["a", "e", "i", "o", "u"]

def remove_vowels(s):
    s_list = list(s)

    for item in s_list:
        if item in vowels:
            s_list.remove(item)

    return s_list
```

> [!warning]
> * `remove()`는 첫 번째 요소만 제거한다.
> * 문자열을 반환하도록 해야 한다.

## 3차 시도: 해결

```python
vowels = ["a", "e", "i", "o", "u"]

def remove_vowels(s):
	s_list = list(s)
	s_list = [x for x in s_list if x not in vowels]

    return "".join(s_list)
```

> [!tip]
> * `for x in s`만으로도 문자열의 각 글자를 하나씩 가져온다.
> * 입력값으로 대문자 모음(`"A"`, `"E"` 등)이 들어올 경우를 대비해 `vowels`에 대문자를 추가하거나 `x.lower()`를 활용하는 것이 좋다.

```python
def remove_vowels(s):
    return "".join(x for x in s if x.lower() not in vowels)
```
